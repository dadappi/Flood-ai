# PJOK Interaktif - Vercel Ready

## Jalankan lokal
```bash
npm install
npm run dev
```

## Deploy ke Vercel
1. Upload project ini ke GitHub
2. Import repository ke Vercel
3. Framework otomatis terbaca sebagai Next.js
4. Build command: `npm run build`
5. Output sudah siap tanpa ubah tampilan atau fungsi

## Catatan
Struktur halaman, pembahasan, soal, skor, dan filter tetap sama.
